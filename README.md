Jilsha Krishna U — Personal Portfolio
A personal portfolio website for Jilsha Krishna U, a B.Tech Computer Science Engineering student.
Preview
Open index.html in a web browser to view the portfolio.
Edit
Open this project folder in Visual Studio Code (VS Code) and edit index.html.
The HTML, CSS, and JavaScript are combined into this single file:
HTML provides the page structure.
CSS is included inside a <style> element.
JavaScript is included inside a <script> element.
No separate style.css or script.js files are required.
Features
About, education, skills, hobbies, career goal, FAQ, and contact sections.
Responsive navigation menu for smaller screens.
Light and dark theme toggle.
Contact form that prepares an email in the visitor's email app.
Contact Form Note
The contact form prepares an email to jilsha13unni@gmail.com in the visitor's email app. It does not save submissions to a website database. The visitor must press Send in their email app.
Social Links
The portfolio includes GitHub and LinkedIn links.
Resume
A resume download button is not included yet because no resume file has been provided. It can be added when the resume is ready.
